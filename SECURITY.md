# Security policy

## Supported version

The latest tagged release is supported. Public Preview interfaces may change before `v1.0`.

## Reporting a vulnerability or sensitive-data exposure

Do not open a public issue for vulnerabilities, leaked credentials, personal data, private source registries, discovery strategies, or production configuration.

Use GitHub's private vulnerability reporting feature for this repository. If that feature is unavailable, contact the maintainer privately through the contact method listed on the repository owner's GitHub profile.

Include the affected version or commit, reproduction steps, impact, and any safe remediation suggestion. Do not access, retain, or redistribute production data beyond what is necessary to report the issue.

## Scope

Reports about the public validators, contracts, build workflow, dependency chain, or accidental sensitive-data inclusion are in scope. Social engineering, denial-of-service testing, and attacks against unrelated hosted services are out of scope.
