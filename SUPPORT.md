# Support

SharBo Globo is a source-available Public Preview. Support requests should stay within the public contracts, validators, documentation, and synthetic demo.

## Before opening an issue

1. Read the [README](README.md), [data contract](docs/DATA_CONTRACT.md), and [localization contract](docs/LOCALIZATION_CONTRACT.md).
2. Search existing issues and the [roadmap](docs/ROADMAP.md).
3. Reproduce behavior with the checked-in synthetic fixture whenever possible.
4. Include the affected version or commit and the smallest useful reproduction.

## Keep private material out

Never include credentials, API keys, personal data, production source names or URLs, private registries, discovery queries, trust weights, operational logs, or real production intelligence in an issue or pull request.

## Security and sensitive-data reports

Do not use a public issue for vulnerabilities or accidental disclosure. Follow [SECURITY.md](SECURITY.md) instead.
