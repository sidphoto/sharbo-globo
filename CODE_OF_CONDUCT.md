# Contributor Covenant Code of Conduct

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socioeconomic status, nationality, personal appearance, race, caste, color, religion, or sexual identity and orientation.

## Our standards

Positive behavior includes empathy, respectful technical disagreement, constructive feedback, accountability, and attention to community safety. Unacceptable behavior includes harassment, discrimination, threats, sexualized conduct, deliberate disclosure of private information, and sustained disruption.

## Enforcement

Project maintainers may remove, edit, or reject contributions and interactions that violate this code. Report conduct issues privately through the repository owner's GitHub profile contact method. Reports will be reviewed with respect for the privacy and safety of everyone involved.

This code is adapted from the Contributor Covenant, version 2.1.
